# AIに指示するとき、私たちは何を渡しているのか ― Meta Muse と Poppy の事例から

AIエージェントに指示する側（Muse や Claude Code の利用者）向けの勉強会資料。本編12枚＋参考資料1枚、約20分＋質疑。

主張：**AIに指示することは、あなたの権限を渡すこと。どこで止まり、どこで止まらないかを知ったうえで任せる。**

| # | 見出し |

| 12 | まとめ：私たちがAIエージェントに渡している3つ（操作する力・あなたの情報・承認する権利） |
