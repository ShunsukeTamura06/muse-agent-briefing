第5章　例② 取り消せない操作（1/2）宣言

事実（発表者の確認）

取り消せない操作は、あらかじめ宣言されている

会社は、権限ごとの影響の大きさを、機械が読める形で示している（実物）

Shopifyのストア（例：Allbirds、土屋鞄製造所）

"dev.ucp.shopping.checkout:manage": {
  "changes": "irreversible",
  "personal_data": true }

「購入の準備」の権限を、取り消せない操作と宣言。説明には「エージェントは購入を準備し、購入を完了するのは買い手」とある

ターキッシュエアラインズ

"flights:search" / "bookings:read" /
"profile:read" →
  すべて "changes": "none"

エージェントに渡せるのは「見る」権限だけ。予約の変更などは、窓口が案内するリンク先で行う

次の問い

「取り消せない」と書いてあれば、それで止まるのか
